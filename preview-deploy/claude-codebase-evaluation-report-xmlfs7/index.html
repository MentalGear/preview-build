    Bridge Log

    Bridge standing by.
    How this works. A deterministic simulation owns the ship — physics, damage, weapons, sensors. The ship's own order parser answers what it recognises; anything else goes to the model brain you pick in Settings, which reads your order plus the current state and answers with the officers' lines and one structured action the page validates and applies. No model ever flies the Excalibur. Impossible orders fail in the simulation and the officer says so.
    Voice. Officers speak through your browser's own speech synthesiser, so their replies cost nothing and are instant. Speech input prefers an on-device recogniser (Moonshine), held down like a radio key and primed with the ship's own vocabulary; it is a one-time download, so the browser's own recogniser — biased toward the same vocabulary where the browser supports contextual biasing — holds the mic until it arrives. Either can be pinned in Settings, and the masthead pill says which is listening. The typed order line always works either way. Damage callouts are spoken from templates the moment the simulation raises them, never waiting on a model.
