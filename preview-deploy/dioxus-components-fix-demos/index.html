Three CSS fixes, before & after

Each demo reproduces the exact current preview/ CSS on the left and the proposed fix on the right. All three are pure CSS — no Rust or wasm — so this behaves like the real gallery will. Best on a phone (iOS Safari for demo 1).

01

Input font-size triggers iOS auto-zoom

Current: .dx-input pins no font-size and controls render at 14px, so iOS Safari zooms the page when you focus a field. Fix: floor form-control font-size to 16px.

On an iPhone: tap each field. The left one zooms the page in; the right one doesn't.

Current
font-size: 14px → zooms on iOS
Fixed
font-size: 16px → no zoom
- font-size: 14px; /* or inherited <16px */ + font-size: 16px; /* at least under @media (pointer: coarse) */
02

Accordion open/close is janky

Current: the keyframes set height at from but grid-template-rows at to, so neither property has both endpoints and neither eases — it snaps. Fix: animate grid-template-rows at both ends, with a gentle ease.

Tap each header to expand and collapse. The left one jumps; the right one glides.

Current
Free returns within 30 days. Tracked shipping on every order; most parcels arrive in 2–4 working days.
Fixed
Free returns within 30 days. Tracked shipping on every order; most parcels arrive in 2–4 working days.
- @keyframes open { from { height: 0 } to { grid-template-rows: 1fr } } /* two props → no interpolation */ + .content { grid-template-rows: 0fr; transition: grid-template-rows 320ms ease } + .content[data-open="true"] { grid-template-rows: 1fr } /* one prop, both ends, gentle curve */
03

Wide dropdowns overflow the page

Current: select/dropdown content sets no max-width, so a menu with a long option grows wider than the screen and pushes the whole page sideways. Fix: clamp overlay width to the viewport.

On a phone (or narrow window): open the left menu — the whole page scrolls sideways and the monitor turns red. The right one clamps to the viewport and wraps.

The max-width clamp stops width-driven overflow like this. A normal-width menu opened hard against the right edge still needs collision-aware repositioning — the larger upstream fix in dioxus-primitives (D-40).

+ .dx-select-content, + .dx-dropdown-content { max-width: calc(100vw - 2rem); } /* clamp to the viewport */
