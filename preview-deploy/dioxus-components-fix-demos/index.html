Three CSS fixes, before & after

Each demo reproduces the exact current preview/ CSS on the left and the proposed fix on the right. All three are pure CSS — no Rust or wasm — so what you see here is what the real gallery will do. Best checked on a phone (iOS Safari for demo 1). Watch the live overflow monitor at the bottom while you open the dropdowns in demo 3.

01

Input font-size triggers iOS auto-zoom

Current: .dx-input pins no font-size and controls render at 14px, so iOS Safari zooms the page when you focus a field. Fix: floor form-control font-size to 16px.

On an iPhone: tap each field. The left one zooms the page in; the right one doesn't.

Current
font-size: 14px → zooms on iOS
Fixed
font-size: 16px → no zoom
- font-size: 14px; /* or inherited <16px */ + font-size: 16px; /* at least under @media (pointer: coarse) */
02

Accordion open/close is janky

Current: the keyframes set height at from but grid-template-rows at to, so neither property has both endpoints and neither eases — it snaps. Fix: animate grid-template-rows at both ends.

Tap each header to expand and collapse. The left one jumps; the right one glides.

Current

Fixed
Free returns within 30 days. Tracked shipping on every order; most parcels arrive in 2–4 working days.
- @keyframes open { from { height: 0 } to { grid-template-rows: 1fr } } + @keyframes open { from { grid-template-rows: 0fr } to { grid-template-rows: 1fr } }
03

Dropdowns overflow the page on small screens

Current: select/dropdown content sets no max-width and positions left: 0, so a menu opened near the right edge extends past the viewport → horizontal page scroll. Fix: clamp overlay width to the viewport.

Open the left menu and watch the monitor turn red — the page now scrolls sideways. The right one stays clamped.
